# GCal Appointment Saver

Chrome extension that adds a paste bar to Google Calendar. Paste appointment info — ICS data, email text, anything — and it opens the event for you to save. Easy peasy.

## How It Works

1. Open Google Calendar — a blue paste bar appears at the top
2. Paste your appointment info (ICS/vCalendar data, email snippets, free text)
3. The extension parses it:
   - **ICS data** (like calendar invites) is parsed instantly, no API key needed
   - **Free text** is sent to AI (Anthropic Claude or OpenAI GPT) for parsing
4. Google Calendar opens with the event pre-filled — just click Save

## Install

1. Clone this repo
2. Open `chrome://extensions` in Chrome
3. Enable **Developer mode** (top right)
4. Click **Load unpacked** and select this folder
5. Open Google Calendar — you'll see the paste bar

## Settings (for free-text parsing)

Right-click the extension icon → **Options** to configure:
- **AI Provider**: Anthropic (Claude) or OpenAI (GPT)
- **API Key**: Your key from the provider

ICS data (calendar invites) works without any API key.

## Example Input

Paste an ICS calendar invite directly:

```
BEGIN:VCALENDAR
BEGIN:VEVENT
DTSTART:20260213T180500Z
DTEND:20260213T184000Z
SUMMARY:Follow Up with Dr. Smith
LOCATION:123 Main St
END:VEVENT
END:VCALENDAR
```

Or paste free text (requires API key):

```
Dentist appointment with Dr. Smith on March 15 at 2:30pm, 123 Main St
```

## Tech Stack

- Chrome Extension (Manifest V3)
- Content script injected on calendar.google.com
- ICS parser (client-side, no dependencies)
- Anthropic Claude API / OpenAI GPT API for free-text parsing
- Google Calendar template URLs for event creation
