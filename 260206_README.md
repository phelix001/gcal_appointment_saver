# gcal_appointment_saver

Paste your appointment info — AI turns it into a real Google Calendar event. Easy peasy.

## What It Does

1. You paste messy appointment details (email text, a screenshot, a quick note — whatever you've got)
2. AI parses it and extracts the date, time, location, title, and description
3. It creates a properly formatted Google Calendar event
4. You review it and add it to your calendar with one click

No more manually copying dates, times, and addresses into calendar fields.
